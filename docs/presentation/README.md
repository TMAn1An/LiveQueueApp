# LiveQueue — Faculty presentation pack

| File | What it is |
|---|---|
| `LiveQueue_Production_Presentation.pptx` | Editable deck (28 slides, speaker notes on every content slide). Diagrams are native, editable PowerPoint shapes. |
| `LiveQueue_Production_Presentation.pdf` | PDF export of the same deck. |
| `livequeue-capacity-analysis.md` | Source of truth for every capacity, bottleneck and cost figure: provider quotas with URLs, formulas, measurements, assumptions, uncertainty and the load-test plan. |
| `livequeue-architecture-summary.md` | Study notes on the production architecture. |
| `faculty-qa.md` | 36 likely questions with answers grounded in the repository. |
| `assets/screenshots/` | Real product screenshots with a fictional demo organization (no real people or data). |
| `source/build-deck.js` | The pptxgenjs script that generates the deck. |

Pricing and quotas were **checked on 2026-10-08**. Capacity figures are engineering estimates — **not load-test validated**. Replace the presenter placeholders on the title slide before presenting.
