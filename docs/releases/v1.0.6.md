## LiveQueue v1.0.6

Organization Head handover, safer Admin replacement, stronger session
revocation and tamper-proof history. Covers only what changed since v1.0.5.

### Installing
- Production-signed with the same LiveQueue release key as v1.0.3–v1.0.5, so it
  installs over v1.0.5 as a normal update — no need to uninstall.

## What's new

### Governance
- **Organization Head succession.** The Head can hand the organization to a
  successor — an Organization Manager, an Executive, or someone new by email.
  Starting it needs the Head's password and an emailed 6-digit code; the
  successor gets a single-use link valid for 72 hours and must explicitly
  accept responsibility. The previous Head's account is closed when the
  handover completes. The Head can cancel; the successor can decline.
- **Head tenure history.** Every Organization Head's tenure is recorded. The
  Head sees the full history with reasons and notes; Managers see the history
  and reasons; Admins and Executives see who the current Head is.
- **Admin workspace replacement.** An Admin who runs a queue or has Executives
  can't be demoted, moved or removed until a replacement Admin takes over. A
  guided handover moves the queue in one step; counters, services, tokens and
  history stay exactly as they are.
- **Every live queue always keeps an Admin.**
- **Executives move with the workspace** — including anyone still invited —
  when an Admin is replaced. New Executives always join an Admin's workspace.

### Security and sessions
- A role, status or workspace change, removal, handover or password reset
  revokes that person's access everywhere at once, consistently.
- Live (real-time) connections are disconnected when access changes, so no
  stale authorization lingers.
- Revocation is precise to the millisecond, so a token issued in the same
  second as a revocation is no longer accepted.

### Audit and history
- Governance actions and their audit entries are saved together, in one step.
- Past service steps keep the names of who served and who referred, even after
  someone leaves.
- Audit entries and governance history can't be edited or deleted.
- Deleting an organization now removes its detailed audit trail and history,
  keeping only a minimal deletion record.

### Invitations
- Invitation links are checked before any password field is shown.
- Expired, used and invalid links all show one plain message.
- Two people accepting the same invitation at the same time can no longer both
  succeed.

### Dashboard
- The Staff area is now called **Associates**.
- Guided Admin replacement when changing an Admin's role or removing them.
- Organization leadership history.
- A step-by-step Head succession wizard.
- Creating an organization no longer waits indefinitely on the name check — it
  says "Still checking" when the server is slow and lets you carry on.
- Fewer unnecessary network round-trips for read requests.

### Services
- The queue-level "Allow multiple services" switch is retired.
- Every journey supports one service or several.
- Existing repeat and ordering rules are unchanged.

### Android app
- Ordered journeys are always on.
