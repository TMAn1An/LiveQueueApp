## LiveQueue v1.0.3

The first LiveQueue Android release signed with the official LiveQueue release
key. From this version on, release tags follow the Android app version.

### Before you install
- Every earlier LiveQueue APK on this page was a test build signed with a
  different key. Android will not update across signing keys, so **uninstall
  any earlier LiveQueue app first**, then install this one. Uninstalling clears
  the app's local history and notifications on that phone.
- Later releases signed with this same key will install as normal updates.

### Joining a queue (Android app)
- Scanning a queue's QR code now opens that queue's services directly, with no
  extra details screen in between.
- Choose when you are reminded before your turn: use the queue's own setting,
  pick 2, 5, 10, 15 or 20 minutes, or set a custom time.
- The Sound and Vibration switches in Notification Settings now really control
  how queue notifications alert you, in any combination.
- Notification Center: the "Mark all read" button and the unread badge are now
  clearly readable.
- Back closes the menu, and the app returns Home after you join a queue.

### Running a queue (web dashboard)
- Counters are managed by owners and admins: they create, rename, open, close
  and delete counters, and decide who works at each one.
- A person can be assigned to at most one counter at a time, across the whole
  system. Moving someone to another counter is a single, explicit step.
- Owners, admins and staff serve only from the counter assigned to them.
  **Serve next** always calls the next person in line, strictly first come,
  first served; there is no counter picker and no sending a person to a
  particular operator.
- The Live Queue header shows the real number of people waiting.
- Form builder: a field's key now follows its label until you edit the key
  yourself, so saved keys never go out of step with labels.
- Neutral "person" and "people" wording throughout, including skip reasons.

### Accounts and dashboard
- Forgot your password? Reset it securely from the sign-in page by email.
- Account and staff emails are cleaner and more reliably delivered.
- Redesigned dashboard: clearer navigation, queue overview, queue settings,
  schedule and capacity setup, staff reports, and help text.
- Organization names are unique, sign-in sessions are more reliable, and a
  temporary backend outage shows a reconnecting state instead of signing you
  out.
