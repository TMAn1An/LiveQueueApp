## LiveQueue v2.1.3

### Web dashboard
- Redesigned web dashboard with a cleaner layout and streamlined info/help text.
- Queue, Counter and Settings screens reworked for clearer day-to-day use.
- Schedule & Capacity: clearer weekly schedule and session-capacity setup.
- Repeat Visits: more flexible repeat-visit restrictions and clearer wording.

### Accounts and reliability
- Organization names are now unique.
- More reliable sign-in sessions.
- During a temporary backend outage the dashboard shows that it is reconnecting
  instead of signing you out.

### Fresh start
- Production has been reset to a clean, empty state. Register your organization
  again to get started; earlier accounts and queues no longer exist.

### Android
- Production Android APK, now signed with the official LiveQueue release key.
- If an earlier (debug-signed) build of the app is installed, uninstall it first:
  Android will not update an app across different signing keys.
